# 공연 티켓 예매 시스템

티켓 오픈 시점에 많은 사용자가 동시에 예매를 시도하는 상황에서도 예약 요청을 안정적으로 처리하고 데이터 정합성을 유지하는 것을 목표로 개발한 티켓팅 프로젝트입니다.
<br>
(2025.07 ~ 진행 중)

---


## 기술 스택

- Language: Java
- Framework: Spring Boot, Spring Data JPA
- Database: MySQL, Redis
- Cloud: AWS (EC2, S3, RDS, ElastiCache, ALB)
- CI/CD: GitHub Actions
